# NSU EEE111L – Multisim Lab Assignment

This repository contains the assignment-1 PDF and Multisim simulation solutions for the EEE111L laboratory course at North South University (NSU), Bangladesh.

## Course Information

- **University:** North South University (NSU)
- **Department:** Electrical and Computer Engineering
- **Course Code:** EEE111L
- **Course Title:** Analog Electronics
- **Semester:** Fall 2026
- **Faculty:** Acq
- **Lab Instructor:** Mehrab Hossain Likhon

## Repository Contents

| File | Description |
|---|---|
| `EEE111L_MultiSim_Assignment_1.pdf` | Original assignment questions |
| `Question_1.ms12` | Multisim solution for Question 1 |
| `Question_2.ms14` | Multisim solution for Question 2 |
| `Question_3.ms14` | Multisim solution for Question 3 |
| `question_4.ms12` | Multisim solution for Question 4 |

## Requirements

- NI Multisim (12th & 14th version)
- A computer capable of running Multisim

## How to Use

1. Download this repository using the **Code → Download ZIP** option.
2. Extract the downloaded ZIP file.
3. Open the assignment PDF to review the questions.
4. Open the corresponding `.ms12` or `.ms14` files using NI Multisim.
5. Run the simulations and inspect the circuit configurations and results.

## Purpose

This repository is intended to serve as an educational reference for NSU students studying EEE111L.

It provides access to the assignment questions and corresponding Multisim simulation files in one place, making it easier for students to review, understand, and practice circuit simulation.
